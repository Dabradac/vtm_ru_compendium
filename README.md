# VTM V5 Компендиум

Модуль Foundry VTT (v13–14) для системы [World of Darkness 5e](https://github.com/WoD5E-Developers/wod5e).

## Компендиумы

Папка «Vampire: The Masquerade V5» во вкладке компендиумов:

| Компендиум | Тип предмета wod5e | Содержимое |
|---|---|---|
| V5: Дисциплины | `power` | 149 сил по папкам: Анимализм, Ясновидение, Стремительность, Доминирование, Стойкость, Сокрытие, Мощь, Величие, Метаморфозы, Кровавое чародейство, Обливион, Алхимия слабокровных, Ритуалы, Церемонии |
| V5: Кланы | `clan` | 13 кланов, Каитифф, Слабокровные: дисциплины, изъян, порок |
| V5: Стили охоты | `predatorType` | 10 стилей с броском охоты |
| V5: Резонансы | `resonance` | 4 темперамента + кровь животных |
| V5: Предыстории, Достоинства и Недостатки | `feature` | предыстории, недостатки предысторий, достоинства, недостатки |
| V5: Оружие | `weapon` | ближний бой и огнестрел с модификатором урона |

Силы дисциплин уже содержат уровень, стоимость (проверки пробуждения) и пул костей:
перетащите силу на лист вампира, и её можно бросать из листа.
У каждого предмета задан `flags.wod5e.dataItemId` (например `power-awe`), поэтому кнопка
синхронизации в листе предмета wod5e находит его в компендиуме.

Описания — краткие пересказы механики. Полные правила — в официальных книгах V5.
Обливион и Ритуалы взяты из дополнений (Players Guide, Cults of the Blood Gods) — их уровни и пулы стоит сверить с книгой.

## Сборка паков

Данные лежат в `src/data/*.mjs`. После правок:

```bash
npm install
npm run build
```

Скрипт `tools/build-packs.mjs` пишет JSON-исходники в `packs/_source/` и компилирует их
в LevelDB-паки `packs/<имя>`, которые читает Foundry. ID документов детерминированы,
так что пересборка не ломает ссылки на предметы.
